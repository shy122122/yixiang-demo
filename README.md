# 飞鸟驿乡 · 智慧乡村产业运营平台

面向乡村文旅与产业运营场景的多端产品原型，统一展示游客服务、商户经营和平台运营三类核心角色。

## 演示模块

- **游客端**：首页、智能导览、AR 文化体验、低空体验预约与支付流程。
- **商户工作台**：经营概览、商品与订单管理、数据分析及履约提醒。
- **运营驾驶舱**：全域经营指标、客流趋势、产业分布与运营风险监测。

## 本地查看

直接打开 `index.html` 即可浏览。顶部切换栏可在三个业务端之间切换，右侧按钮可单独打开当前原型页。

## GitHub Pages 部署

仓库上传到 GitHub 后，在 **Settings → Pages** 中选择从 `main` 分支根目录部署。发布后可通过统一入口访问全部原型。
